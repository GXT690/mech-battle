A
01 · 诱发性事件 A
A 是什么？
A 是触发我们情绪反应的外部事件、情境或他人行为。
它只是一根「火柴」，本身并不决定火焰的大小。
A · Activating Event
A
诱发性事件
发生在外部世界的、客观存在的事实。
例如：被批评 · 错过机会 · 堵车 · 分手 · 被忽视
客观事实 — 02 / 07 —
B
02 · 信念与看法 B
B — 真正的开关
B 是我们对事件所持有的信念、解释、评价和看法。
这才是真正决定我们情绪反应的关键。
B · Beliefs
B
信念 · 解释 · 评价
我们内心对事件的解读方式。
合理的信念带来平静 · 不合理的信念放大痛苦
主观解读 — 03 / 07 —
C
03 · 情绪与行为结果 C
C 是结果
C 是在特定情境下，我们产生的情绪感受与行为反应。
它是 B 的直接产物——而非 A 的。
C · Consequence
C
情绪与行为结果
我们感受到的一切情绪与行为。
愤怒 · 焦虑 · 沮丧 · 平静 · 理解 · 行动
内在感受 — 04 / 07 —
核心逻辑 FLOW
不是 A→C
而是 A→B→C
事件 A 只是间接原因，
你对事件的信念 B 才是情绪 C 的直接来源。
A
事件发生
别人迟到 · 堵车 · 被批评
→ B →
B
我的解读
TA不尊重我 vs TA可能有原因
→ C →
C
情绪反应
愤怒崩溃 vs 理解与沟通
· THE KEY INSIGHT ·
你无法改变 A，
但你永远可以改变 B，
从而改变 C。

生活场景 · 示例 CASE
当朋友
忘了回复你
A · 发生的事实
朋友三小时未回复你的消息。
不合理 B
TA 根本不在乎我，我们的友情一文不值。 → C：难过 · 愤怒 · 自我怀疑
合理 B
TA 可能正忙，或者手机不在身边，这不代表什么。 → C：平静 · 理解 · 晚些再联系

Takeaway
你不是
被事件左右，

先停下来，问自己：
